SAX bitmap patterns visualization

How to use SAX for bitmap-like time series pattern visualization.

As the authors of this technique explained, the time series bitmap is "…a simple parameter-light tool that allows users to efficiently navigate through large collections of time series…". Based on SAX transform and occurrence frequency counting, the time series bitmap algorithm transforms any input time series (or its segment) into a bitmap, where each SAX word’s frequency is mapped to a color cell. Similar series produce similar bitmaps, which makes them easy to scan visually.
